# Lost-N-Found-FrontEnd

## Getting Started

### Clone the Repository

To clone the repository locally, run:

```bash
git clone https://github.com/438-Lost-N-found/Lost-N-Found-FrontEnd.git
```

## Running the Application Locally

### 1. Install Node.js

Download and install Node.js from:

https://nodejs.org/en/download

### 2. Install Dependencies

Navigate to the project directory and install the required dependencies:

```bash
npm install
```

### 3. Navigate to the Application Folder

Open a terminal and run:

```powershell
cd Lost-N-Found-FrontEnd
cd NatApp
```

### 4. Start the Application

Launch the Expo development server:

```bash
npx expo start
```

### 5. View the Application

Once the Expo server starts:

- Click the provided web link to open the application in your browser.
- Scan the QR code using the Expo Go app on your mobile device to run the application on your phone.

## Requirements

- Node.js
- npm (included with Node.js)
- Expo Go (for mobile testing)

## Troubleshooting

If dependencies fail to install, ensure that Node.js and npm are installed correctly:

```bash
node --version
npm --version
```

You can also clear and reinstall dependencies:

```bash
rm -rf node_modules
npm install
```

## Project Status

The frontend and backend are currently being developed independently and are not yet integrated. As a result, neither repository depends on the other at this stage of development.

Both projects can be cloned, installed, and run separately:

- The frontend can be launched independently for UI and user experience development.
- The backend can be run independently for API, database, and server development.

Integration between the frontend and backend will be completed in a future update once the API connection layer is implemented.
